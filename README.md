# 부산 실시간 CCTV 멀티뷰

부산광역시 교통정보서비스센터(its.busan.go.kr)가 공개하는 교통 CCTV를
**여러 대 동시에** 보고, 기록하고, 교통량을 재는 단일 HTML 앱입니다.

- 웹: **https://jyseok0311.github.io/busan-cctv-multiview/**
- 로컬: `index.html` 을 브라우저로 열면 됩니다 (단, 주차장·단속 레이어와 앱 설치는 http(s) 로 열었을 때만 동작)

## 왜 만들었나

UTIC(도시교통정보센터)과 부산시 사이트는 CCTV를 **한 번에 하나씩만** 보여줍니다.
UTIC은 `PopupCctv` 라는 고정 이름의 창을 재사용해서 다른 카메라를 누르면 같은 창을 덮어쓰고,
재생도 60초로 제한됩니다. 이 앱은 부산시가 공개하는 HLS 주소를 직접 받아 격자로 띄우며 시간 제한이 없습니다.

## 기능

| 영역 | 내용 |
|---|---|
| 멀티뷰 | 일반 CCTV 337곳 + 스마트교차로 89곳(카메라 322대), 1~6열 격자, 드래그로 자리 이동 |
| 교차로 일괄 | `＋N방향` 으로 한 교차로의 모든 진입로를 한 번에 |
| 실시간 상황 | 사고·공사·정체·침수 피드(1분 갱신). **돌발 자동추적**을 켜면 그 지점 CCTV가 자동으로 올라오고 배지가 붙음 |
| 지도 | 카메라·돌발 마커, 관측 후 교통량 히트맵, **경로를 그어** 반경 안 CCTV 일괄 선택 |
| 주차장 | 부산 701곳(무료 40곳). 무료만 필터, 팝업에서 요금·면수·운영시간과 **가까운 CCTV 보기** |
| 단속카메라 | 부산 497개(12개 구). 제한속도 표시. *단속 종류는 원본이 코드값이라 표기하지 않음(아래 참고)* |
| 날씨 | 보고 있는 CCTV 지점의 기상청 실황 + 6시간 강수 전망. 비 예보 시 경고 (인증키 필요, 아래 참고) |
| 화면 | 더블클릭·⛶ 로 크게 보기, 크게 본 상태에서 휠 확대, 두 손가락 핀치 줌, 확대 표현(부드럽게/픽셀/윤곽), 원본 초과 확대 표시 |
| 녹화 | 개별 화면 녹화, 격자 전체를 분할화면 한 영상으로(시각 표시), 모션 감지 시 자동 녹화 |
| AI 계수 | 브라우저 GPU(TensorFlow.js)로 차량 추적 → 검지선 통과 계수(대/시). 전역 스캔으로 전 지점 밀도 기록 |
| 기록 | IndexedDB 시계열(14일 보관, 막힌 환경은 임시 저장으로 폴백), 이상 징후 판정, CSV 내보내기 |
| 편의 | 프리셋 저장, 순회 모드, 공유 링크(화면 구성을 URL 로), PiP, 브라우저 알림, 홈 화면 앱(PWA) |

모바일: 서랍형 목록, 접이식 도구막대, 터치 드래그, 핀치 줌, 첫 실행 시 1열.

## 데이터 출처

| 데이터 | 출처 | 방식 |
|---|---|---|
| CCTV 목록·돌발·정체·침수 | `its.busan.go.kr/api-n/v1/bsits/user/…` | 실시간 호출 (키 불필요) |
| 영상 | `its-stream*.busan.go.kr:8443/rtplive/*.stream/playlist.m3u8` | HLS |
| 주차장·단속카메라 | [공공데이터포털](https://www.data.go.kr) 구·군별 CSV | `data/*.json` 으로 변환해 정적 포함 |
| 날씨 | [기상청 단기예보 조회서비스](https://www.data.go.kr/data/15084084/openapi.do) | 실시간 호출 (인증키 필요) |
| 지도 타일 | OpenStreetMap | |
| 라이브러리 | hls.js 1.5.17, Leaflet 1.9.4, TensorFlow.js 4.22 + COCO-SSD | CDN |

데이터 기준일은 앱 지도에서 레이어를 켤 때 표시되며 `data/meta.json` 에 있습니다.

## 주차장·단속카메라 데이터 준비

1. 공공데이터포털에서 **부산광역시_○○구_주차장정보.csv**, **부산광역시_○○구_무인교통단속카메라.csv** 를 내려받습니다
   (전국주차장정보표준데이터 / 전국무인교통단속카메라표준데이터 계열이면 컬럼이 같습니다)
2. 이 폴더 안에 넣습니다 (하위 폴더도 됩니다). 파일명에 `주차장` / `단속` 이 들어 있어야 합니다
3. `데이터변환.ps1` 우클릭 → *PowerShell에서 실행*
4. `data/parking.json`, `data/cameras.json`, `data/meta.json` 이 만들어집니다. 커밋해서 배포하면 끝

원본 CSV 는 `.gitignore` 로 제외되어 변환 결과만 저장소에 올라갑니다.

## 기상청 날씨 인증키

1. data.go.kr 에서 **기상청_단기예보 조회서비스** 활용신청 (자동승인)
2. 앱 상단 `🌦 날씨` 옆 `🔑` 를 눌러 **일반 인증키(Encoding)** 를 붙여넣습니다

키는 **그 브라우저의 localStorage 에만** 저장됩니다. 저장소에는 넣지 마세요 — 공개 저장소에 올라가면
누구나 쓸 수 있어 일일 호출 한도가 소진됩니다. 앱은 결과를 10분 캐시하므로 하루 300회 안쪽으로 씁니다.

## 폰에서 보기

배포 주소를 열고 "홈 화면에 추가" 하면 앱처럼 뜹니다.
같은 와이파이에서 PC 의 파일을 바로 보려면 `폰으로보기.ps1` 을 실행하면 접속 주소가 표시됩니다
(단, `http://192.168.x.x` 는 보안 컨텍스트가 아니라 위치·알림·앱 설치가 동작하지 않고,
부산시 API 가 이 출처를 막아 실시간 상황·침수 탭이 비어 보일 수 있습니다. 배포 주소에서는 정상입니다).

## 알아둘 점

**AI 계수의 한계.** 검지선 통과 방식이라 유량(대/시)은 지점 간 비교가 가능하지만,
정확도를 실측과 대조하지 않았습니다. 야간·우천에는 검지율이 떨어지고 정체가 심해 차량이 겹치면
과소 계수됩니다. 연구에 쓰려면 한 지점에서 수동 계수와 대조해 오차율을 먼저 구해야 합니다.

**밀도 지표는 지점 간 비교 불가.** '화면 내 차량 수'는 카메라 화각·줌에 좌우되므로
같은 지점의 시간 변화만 의미가 있습니다.

**단속카메라는 부산 전체가 아닙니다.** 12개 구 자료만 있고 금정·영도·수영구·기장군은 없습니다.
또 원본의 `단속구분` 이 코드값(3·4)이고 공식 코드표를 확인하지 못해, 과속·신호·주정차를
단정하지 않고 **확인된 제한속도만** 표시합니다. 지도에 없다고 단속카메라가 없는 것은 아닙니다.

**iOS 사파리 제약.** 아이폰·아이패드는 영상 픽셀을 캔버스로 읽지 못하게 막혀 있어
AI 검지·모션 감지·녹화가 동작하지 않습니다. 영상 보기와 나머지 기능은 정상입니다.

**운전 중에는 보지 마세요.** 목적지 주차장·경로 상황을 출발 전에 확인하는 용도입니다.

**개인정보.** 차량·보행자를 익명 상자로 세기만 합니다. 번호판 판독·얼굴 인식·개인 추적은
구현하지 않았고, 저장되는 것은 지점별 숫자뿐이며 영상 프레임은 어디에도 저장되지 않습니다.

## 데이터 오류 보정

부산시 API 가 광안리해수욕장사거리(`I000270`)를 남구로 분류하고 있으나 실제로는 수영구입니다
(같은 지점의 일반 CCTV 주소가 `수영구 광안동 191-5`, 남구로 분류된 나머지 교차로는 모두 위도 35.140 이하인데
이곳만 35.155). 소스의 `GU_FIX` 에서 보정합니다.
